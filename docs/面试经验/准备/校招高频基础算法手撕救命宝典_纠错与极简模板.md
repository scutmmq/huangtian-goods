## 第一部分：新凯来一面“斐波那契 + 二分查找”真题错因深度解剖（4 大致命 Bug 修正）

### ❌ 回顾你在新凯来考场上写的原始代码：
```java
public int search(int value, int[] fn) {
    int left = 0;
    int right = fn.length - 1;
    int mid = // 【Bug 1】循环外未正确初始化，且放在循环末尾更新容易漏算
    while (left != right) { // 【Bug 2】致命死循环！不能用 !=，必须用 <=
        if (fn[mid] < value) {
            left = mid + 1;
        } else if (fn[mid] > value) {
            right = mid - 1;
        } else if (fn[mid] == value) {
            return mid;
        }
        // 【Bug 3】致命算错位置！忘了加 left！应该是 left + (right - left) / 2
        mid = (right - left) / 2; 
    }
    // 【Bug 4】找不到不能返回 0！因为 0 是数组第一个元素的合法下标！应返回 -1
    return 0; 
}
```

### 🔍 为什么考场上这 4 个地方全错了？（逐条把根拔掉）

1. **【Bug 1 & Bug 3】`mid` 怎么算？写在哪里？**
   * **错误写法**：`mid = (right - left) / 2;`
   * **为什么错**：`(right - left) / 2` 算出来的只是**区间长度的一半（偏移量）**，不是数组下标！比如 `left = 4, right = 6`，中点下标显然是 `5`，但 `(6 - 4) / 2 = 1`，直接跳回下标 `1` 了！
   * **正确写法**：永远写在 `while` 循环体的**第一行**：
     ```java
     int mid = left + (right - left) / 2; // 起点 left + 偏移量的一半（且防止 left+right 溢出）
     ```

2. **【Bug 2】为什么 `while (left != right)` 会导致漏查甚至死循环？**
   * **漏查问题**：当 `left == right` 重合时（比如只剩最后一个元素还没检查），`left != right` 直接为 `false` 退出循环，**正巧要找的数就在最后一个位置时直接漏掉**！
   * **越界死循环问题**：假设 `left = 0, right = 1`，此时 `mid = 0`。如果要找的数比 `fn[0]` 还小，执行 `right = mid - 1 = -1`。下一轮判断 `left(0) != right(-1)` 依然成立！继续循环访问 `fn[-1]` 直接抛出数组越界异常崩溃！
   * **正确写法**：闭区间 `[left, right]` 下，条件永远是 **`while (left <= right)`**！

3. **【Bug 4】找不到时返回什么？**
   * 数组下标是从 `0` 开始的，如果返回 `0`，调用方根本分不清“是在第 0 个位置找到了”还是“没找到”。**任何查找算法未找到时，统一返回 `-1`**！

### 模板 1：斐波那契数列生成 + 标准二分查找（闭区间 `[left, right]` 万能法）

> 🧠 **三句口诀**：  
> 1. **`left = 0, right = n - 1`，循环条件 `left <= right`；**  
> 2. **进循环第一行算 `mid = left + (right - left) / 2`；**  
> 3. **小了 `left = mid + 1`，大了 `right = mid - 1`，找不到返 `-1`。**

```java
import java.util.Arrays;

public class FibonacciAndBinarySearch {
    // 函数 1：生成长度为 n (n < 20) 的斐波那契数列：1, 2, 3, 5, 8, 13, 21...
    public static int[] generateFibonacci(int n) {
        if (n <= 0 || n >= 20) {
            throw new IllegalArgumentException("长度 n 必须在 1 到 19 之间");
        }
        int[] fib = new int[n];
        fib[0] = 1;
        if (n > 1) {
            fib[1] = 2;
        }
        for (int i = 2; i < n; i++) {
            fib[i] = fib[i - 1] + fib[i - 2]; // 当前项 = 前两项之和
        }
        return fib;
    }

    // 函数 2：在有序数组中二分查找 target，找到返回下标，找不到返回 -1
    public static int binarySearch(int[] nums, int target) {
        if (nums == null || nums.length == 0) return -1;
        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2; // 必须写在循环第一行！记得加 left！
            if (nums[mid] == target) {
                return mid;                      // 找到目标，直接返回下标
            } else if (nums[mid] < target) {
                left = mid + 1;                  // 目标在右半区
            } else {
                right = mid - 1;                 // 目标在左半区
            }
        }
        return -1;                               // 未找到返回 -1
    }

    public static void main(String[] args) {
        int[] fib = generateFibonacci(10);
        System.out.println("生成的斐波那契数列: " + Arrays.toString(fib));
        System.out.println("查找数字 13 的下标: " + binarySearch(fib, 13)); // 输出 5
        System.out.println("查找数字 99 的下标: " + binarySearch(fib, 99)); // 输出 -1
    }
}
```

### 模板 2：快速排序（QuickSort —— 双指针挖坑填数法，最好记！）

> 🧠 **三句口诀**：  
> 1. **选最左边元素 `pivot = arr[left]` 当基准（相当于在 `left` 挖了个坑）；**  
> 2. **必须先从右往左找比 `pivot` 小的数填到左坑 `arr[i] = arr[j]`，再从左往右找比 `pivot` 大的数填到右坑 `arr[j] = arr[i]`；**  
> 3. **相遇时把 `pivot` 填回中间坑位 `arr[i] = pivot`，递归排左右两半！**

```java
public class QuickSortTemplate {
    public static void quickSort(int[] arr, int left, int right) {
        if (left >= right) return; // 递归终止条件：区间只有 1 个或 0 个元素

        int i = left, j = right;
        int pivot = arr[left];     // 1. 挖坑：保存最左边的基准值

        while (i < j) {
            // 2. 必须先从右往左找第一个 < pivot 的数
            while (i < j && arr[j] >= pivot) {
                j--;
            }
            if (i < j) arr[i] = arr[j]; // 填到左边的坑，此时 j 变成新坑

            // 3. 再从左往右找第一个 > pivot 的数
            while (i < j && arr[i] <= pivot) {
                i++;
            }
            if (i < j) arr[j] = arr[i]; // 填到右边的坑，此时 i 变成新坑
        }

        arr[i] = pivot;            // 4. i 和 j 相遇，把基准值填回最终坑位
        quickSort(arr, left, i - 1);  // 递归排左半边
        quickSort(arr, i + 1, right); // 递归排右半边
    }
}
```

### 模板 3：反转单链表（迭代三指针法）+ 快慢指针判环

> 🧠 **反转链表四步口诀（循环内 4 行代码形成闭环）**：  
> 1. **存后继：`ListNode next = curr.next;`**  
> 2. **扭指针：`curr.next = prev;`**  
> 3. **prev 前移：`prev = curr;`**  
> 4. **curr 前移：`curr = next;`**

```java
public class LinkedListTemplates {
    static class ListNode {
        int val;
        ListNode next;
        ListNode(int val) { this.val = val; }
    }

    // 1. 反转单链表：1 -> 2 -> 3 -> null 变成 3 -> 2 -> 1 -> null
    public static ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode next = curr.next; // ① 先暂存下一个节点，防止断链丢失
            curr.next = prev;          // ② 将当前节点指针反转指向前驱
            prev = curr;               // ③ prev 往前走一步
            curr = next;               // ④ curr 往前走一步
        }
        return prev; // 最终 prev 就是反转后的新头节点
    }

    // 2. 判断链表是否有环（快慢指针：慢指针走 1 步，快指针走 2 步，相遇即有环）
    public static boolean hasCycle(ListNode head) {
        ListNode slow = head, fast = head;
        while (fast != null && fast.next != null) {
            slow = slow.next;          // 慢指针走 1 步
            fast = fast.next.next;     // 快指针走 2 步
            if (slow == fast) return true; // 套圈相遇，说明有环
        }
        return false;
    }
}
```

### 模板 4：两数之和（HashMap 一遍扫描 $O(n)$）

> 🧠 **核心思路**：遍历数组时，计算“还需要凑多少（`need = target - nums[i]`）”，去 `HashMap` 里查有没有这个 `need`；有就直接返回两个下标，没有就把当前数字和下标存进 `Map`。

```java
import java.util.HashMap;
import java.util.Map;

public class TwoSumTemplate {
    public static int[] twoSum(int[] nums, int target) {
        // Key: 数组里的数值, Value: 该数值所在的下标
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (map.containsKey(need)) {
                return new int[]{map.get(need), i};
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }
}
```

### 模板 5：有效的括号匹配（栈 `ArrayDeque` 标准写法）

> 🧠 **精妙技巧**：遇到左括号 `(`、`[`、`{` 时，**直接把对应的右括号 `)`、`]`、`}` 压入栈中**！这样遇到右括号时，只需判断“栈是否为空 或 弹出的字符是否等于当前字符”即可，省去了繁琐的配对判断！

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class ValidParenthesesTemplate {
    public static boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            // 如果是右括号：若栈空（说明右括号多了）或弹出的不匹配，直接 false
            else if (stack.isEmpty() || stack.pop() != c) {
                return false;
            }
        }
        return stack.isEmpty(); // 最后栈必须清空（防止左括号多出来）
    }
}
```

### 模板 6：二叉树的前/中/后序递归遍历 + 层序遍历（BFS 队列）

```java
import java.util.*;

public class BinaryTreeTemplates {
    static class TreeNode {
        int val;
        TreeNode left, right;
        TreeNode(int val) { this.val = val; }
    }

    // 1. 递归最大深度（分治入门：左右子树最大深度 + 1）
    public static int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
    }

    // 2. 层序遍历（BFS 广度优先队列：一层一层打印节点）
    public static List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> res = new ArrayList<>();
        if (root == null) return res;

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size(); // 锁定当前层的节点个数
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            res.add(level);
        }
        return res;
    }
}
```

### 模板 7：动态规划 & 贪心入门——最大子数组和（Kadane 算法，仅需 6 行！）

> 💡 **题目**：给定整数数组 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`，找出具有最大和的连续子数组（`[4, -1, 2, 1]`，最大和为 `6`）。  
> 🧠 **核心口诀**：如果前面的累加和 `curSum` 小于 0（是负资产累赘），就果断扔掉它，从当前数字重新开始算；否则就加上当前数字！

```java
public class MaxSubArrayTemplate {
    public static int maxSubArray(int[] nums) {
        int curSum = nums[0];
        int maxSum = nums[0];
        for (int i = 1; i < nums.length; i++) {
            // 如果之前累加和 > 0 就接着加，否则另起炉灶从 nums[i] 开始
            curSum = Math.max(nums[i], curSum + nums[i]);
            maxSum = Math.max(maxSum, curSum);
        }
        return maxSum;
    }
}
```

### 模板 8：动态规划核心——0-1 背包问题（TPLINK 二面真题，一维滚动数组逆序）

> 💡 **题目**：背包最大承重为 `V`，有 $n$ 件物品，重量数组为 `weight[]`，价值数组为 `value[]`，每件物品只能用一次，求能装入的最大价值。  
> 🧠 **状态转移方程口诀**：  
> * `dp[j]` 表示容量为 `j` 的背包能装的最大价值；  
> * **外层正序遍历物品 `i`，内层必须逆序遍历容量 `j`（从 `V` 倒着减到 `weight[i]`）**，防止同一件物品被重复放入多次！  
> * 方程：**`dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);`**（不装第 `i` 件 vs 腾出 `weight[i]` 空间装第 `i` 件）。

```java
public class Knapsack01Template {
    public static int knapsack01(int V, int[] weight, int[] value) {
        int[] dp = new int[V + 1];
        for (int i = 0; i < weight.length; i++) {
            // 核心铁律：0-1 背包一维优化，容量 j 必须从大到小逆序遍历！
            for (int j = V; j >= weight[i]; j--) {
                dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
            }
        }
        return dp[V];
    }
}
```

### 模板 9：多线程手撕——DCL 单例模式 + 两线程交替打印 1~100 奇偶数

```java
public class ConcurrencyHandCoding {
    // 1. DCL 双重检查锁定单例（必加 volatile 防指令重排）
    static class Singleton {
        private static volatile Singleton instance;
        private Singleton() {}
        public static Singleton getInstance() {
            if (instance == null) {
                synchronized (Singleton.class) {
                    if (instance == null) {
                        instance = new Singleton();
                    }
                }
            }
            return instance;
        }
    }

    // 2. 两个线程交替打印 1~100（notify 唤醒对方 + wait 挂起自己）
    private static int count = 1;
    private static final Object LOCK = new Object();

    public static void printOddEven() {
        Runnable task = () -> {
            while (count <= 100) {
                synchronized (LOCK) {
                    System.out.println(Thread.currentThread().getName() + ": " + count++);
                    LOCK.notify(); // 唤醒对方线程
                    if (count <= 100) {
                        try {
                            LOCK.wait(); // 释放锁并挂起自己
                        } catch (InterruptedException e) {
                            Thread.currentThread().interrupt();
                        }
                    }
                }
            }
        };
        new Thread(task, "奇数线程").start();
        new Thread(task, "偶数线程").start();
    }
}
```

### 模板 10：企业级业务手撕——Java 8 Stream 分组过滤与 BigDecimal 聚合

```java
import java.math.BigDecimal;
import java.util.*;
import java.util.stream.Collectors;

public class StreamGroupTemplate {
    static class Order {
        String dept;
        BigDecimal amount;
        boolean valid;
        public String getDept() { return dept; }
        public BigDecimal getAmount() { return amount; }
        public boolean isValid() { return valid; }
    }

    // 过滤有效订单，按部门分组并求各部门总金额
    public static Map<String, BigDecimal> sumByDept(List<Order> orders) {
        return orders.stream()
            .filter(Order::isValid)
            .collect(Collectors.groupingBy(
                Order::getDept,
                Collectors.reducing(BigDecimal.ZERO, Order::getAmount, BigDecimal::add)
            ));
    }
}
```
